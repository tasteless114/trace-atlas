# 行迹 · TRACE ATLAS

本地运动足迹与热图应用。用浏览器打开 **http://127.0.0.1:8787** 就能看，支持 **FIT / TCX / GPX** 三种文件，骑行、跑步、徒步记在同一份本地库里，按类型分开看。底图用国内可直接访问的高德地图，原始文件不会被修改。

## 点开就用

整个应用只用 **Python 标准库**，加上内置在 `vendor/` 里的 FIT 解码器：

- 不需要 `pip install`，不需要虚拟环境，第一次运行也不用联网。
- 机器上有 Python 3.10+ 即可（安装时勾选 **Add Python to PATH**），双击 **启动行迹.cmd** 就能用。
- 双击 **停止行迹.cmd** 结束后台服务。关闭网页不会停止服务。
- 也可以在项目目录运行 `python server.py`，`Ctrl+C` 停止。

程序只监听 `127.0.0.1`，不设开机启动。

## 放文件的地方

所有运动文件放进项目内的 **`运动数据`** 文件夹（支持任意子文件夹），启动时自动扫描。之后新增文件，点网页里的 **＋ → 重新扫描**。

也可以把文件直接拖到导入区的上传框，或点它多选文件；浏览器按每批 200 个处理，显示进度和失败原因。

从旧版本升级时，`fit/`、`tcx/`、`rides/` 会在启动时自动合并进 `运动数据/`。

默认目录、端口、进程数、离线地图缩放范围都在 `config.json` 里改。

## 使用

1. 打开默认进 **足迹线条** 模式：把走过的路用统一颜色叠成清晰细线。地图自动定位到**最近一次活动**，**查看全部**显示跨地区的全部足迹。
2. **热力图** 模式把每条轨迹按覆盖次数着色，走过越多次越暖。
3. 运动类型可选 **全部运动 / 骑行 / 跑步 / 步行·徒步 / 仅含 GPS**。GPX 的类型读 `<trk><type>`，没有就归到「其他」。
4. 可按日期、今年、近 90 天、文件名筛选；**仅含 GPS** 隐藏室内或无定位的活动。
5. **点地图上的任意一条路径**就会认出是哪次活动，弹出卡片（日期、距离、用时、爬升、文件名）。点卡片上的 **查看更多数据** 展开明细 —— 心率、功率、踏频、最高速度；跑步显示 **平均配速和步频**。文件里没有的项自动隐藏。
6. 也可以点左侧列表的记录，效果相同（顺带把视野缩放过去）。按 `Esc` 或点卡片 ✕ 取消选择。
7. 足迹模式可调线宽、亮度、颜色；热图模式可调线宽和色温强度。
8. **3D 爬升** 模式（MapLibre GL，内置无密钥）：卫星底图，可俯仰旋转。选中的活动**按海拔上色**（青 → 绿 → 黄 → 橙 → 红），其他活动淡蓝细线做参照，点轨迹同样能认活动。
   - 可调 **轨迹精度**（0.4–4 像素：越细越贴真实轨迹，越粗越省性能）、**俯仰**、**旋转**。
   - **3D 地形** 开关（默认关）：接开放高程数据，地面真的起伏。
   - **线条颜色**：默认按海拔着色；关掉后是单色（橙 / 灰绿 / 白 / 珊瑚）。
9. 右上角 **隐藏面板**（或按 `H`）收起左侧面板，让地图铺满窗口。
10. 地图加载慢时点 **下载离线地图**，把轨迹覆盖的区域存到本机，之后断网也秒开。

单个文件上限 50 MB。完整轨迹存在压缩数据库里；足迹模式包含全部筛选活动，按视野加载，放大到 13 级以上用原始 GPS 点。

## 底图

三种可选：**高德路网**（默认）、**高德卫星**、**无底图**。3D 视图固定用卫星影像（路网图斜着看是一张密网）。

瓦片不由浏览器直接请求，而是先经过本机服务：

- 每块瓦片只向上游请求一次，之后存到 `data/tiles/`，由磁盘直接返回，带 30 天浏览器缓存。
- 内存里还有一层最近瓦片缓存，浏览时自动预取下一级和两级瓦片。
- 缓存超过约 24,000 个文件时自动清理最旧部分。
- 上游不可用时提示，可切离线模式。

只有当前视野附近和路线上的瓦片会被请求，不会批量下载无关区域。

## 离线地图

右侧面板的 **下载离线地图** 会把**你自己轨迹覆盖的区域**整片存到本机：

- 覆盖缩放级别 8–16，凭轨迹算出需要的瓦片，已存在的跳过，可随时停止和续传。
- 存好后这部分区域完全不需要联网。
- 想清空直接删 `data/tiles`，程序会重新下载。
- 缩放范围可在 `config.json` 调整：`offline_min_zoom`、`offline_max_zoom`、`offline_max_tiles`。

## 性能

- **多进程**：导入、简化、投影都是纯 Python 计算，按 CPU 数开进程（最多 12 个）。
- **几何缓存**：每条轨迹只在第一次被需要时简化投影一次，之后平移只是重新裁剪整数坐标。
- **传输格式**：坐标是 zoom 20 的整数 Web-Mercator 像素，delta 编码后 base64，体积约为 JSON 的四分之一。
- **平移不重载**：一次取比屏幕大一圈（四周各留 45%）的数据，平移还在范围内就完全不请求，画面也不闪。
- **绘制**：两条 canvas 图层直接描边，叠层在多个 Worker 线程里并行上色。

## 热度怎么算

热力图不是模糊色块，而是一条条按叠加次数着色的轨迹：

- 每条轨迹画一次线，同一位置被多少条覆盖就累积多少层 —— 也就是"这条路走过多少次"。
- 层数映射成色温：一次是冷色，走过几十次的干道烧成橙红。颜色相对当前视野里的最大叠加。
- 线条就在真实轨迹上，不会把相邻道路糊到一起；操场、匝道、桥下穿行都能分开。
- 一次活动在同一条路上往返记两层 —— 正是"在这条路上花了多少时间"。

## 坐标对齐

FIT / TCX / GPX 里的坐标是 **WGS84**，国内底图用 **GCJ-02**（火星坐标），相差几百米。轨迹坐标默认 **自动匹配底图**：用国内底图时换算成 GCJ-02 对齐，无底图时保持原始坐标。

如果文件本身已是 GCJ-02（某些国内软件导出），把 **轨迹坐标** 改成 **源文件为 GCJ-02**。换算只影响显示，不写回原文件，也不改数据库里的原始坐标。

## 数据在哪

- **`运动数据/`**：你放进去的 FIT / TCX / GPX 源文件，程序不会修改。
- **`data/rides.sqlite3`**：活动汇总、压缩轨迹、逐点海拔、心率/功率/踏频。旧版本导入的记录会在启动后自动回填。
- **`data/tiles/`**：底图缓存，可随时删除。
- **`data/server.log`、`data/server-error.log`**：日志（只记出错请求）。
- 上传文件只在本机临时保存，解析完删除临时副本。

备份时停止服务，复制整个 `data` 文件夹；只想备份记录的话复制 `rides.sqlite3` 就够，瓦片缓存不必备份。

解析、筛选、绘制全部在本机，没有账户，没有第三方分析。底图瓦片由本机服务向高德请求后缓存，高德能看到你的 IP 和浏览的瓦片区域，但收不到活动文件或完整轨迹。

## 分享给朋友

双击 **打包分享版.cmd** 生成 **行迹_分享版.zip**，内含代码、界面、内置解码器、启动脚本和一个空的 `运动数据` 文件夹。

打包用文件白名单，自动排除个人活动文件、`data` 数据库与瓦片缓存、`__pycache__`。朋友的电脑需要 Python 3.10+，解压后双击 **启动行迹.cmd** 即可，不需要装依赖、不需要联网。

## 技术与依赖

- 运行环境：**Python 3.10+ 标准库**（`http.server`、`sqlite3`、`xml.etree`、`zlib`、`multiprocessing`）。没有第三方包，没有构建步骤。
- FIT 解码器：`vendor/fitparse`（python-fitparse 1.2.0，MIT）。
- 前端：Leaflet 1.9.4（2D）+ MapLibre GL JS 5.10（3D），都在 `static/vendor`，无 CDN、无密钥。3D 需要浏览器支持 WebGL。
- 坐标转换公式来自 wandergis/coordTransform_py（MIT）。

许可文件：`vendor/fitparse/LICENSE.txt`、`static/vendor/LEAFLET-LICENSE.txt`、`static/vendor/MAPLIBRE-LICENSE.txt`、`LICENSE-COORD-TRANSFORM.txt`。
